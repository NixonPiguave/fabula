DOCUMENTS AND GRAPHICS
PDF.js has optional font and graphics dependencies. Package notices are in
LICENCIAS_DE_COMPONENTES.txt. assets/licenses/canvas-sbom.json preserves the
native dependency inventory supplied by the Windows canvas package. That
inventory does not replace component notices or source obligations; review
these dependencies and preserve their notices before public binary distribution.
Extraction and recognition use Tesseract.js and Tesseract.js Core (Apache-2.0),
fflate (MIT), fast-xml-parser (MIT), html-to-text (MIT), rtf-parser (ISC),
docx (MIT) and @napi-rs/canvas (MIT). Their packages preserve their licenses.

OPTIONAL MODULES
These are downloaded separately and are not included in Fábula's executable:
- Spanish OCR: spa.traineddata, tessdata_fast 4.1.0, Apache-2.0
  https://github.com/tesseract-ocr/tessdata_fast/tree/4.1.0
- Windows x64 CPU Whisper engine: whisper.cpp b5454, MIT
  https://github.com/ggml-org/whisper.cpp/releases/tag/b5454
- Multilingual Whisper Base model, MIT
  https://huggingface.co/ggerganov/whisper.cpp
src/main/modules.ts pins download versions, sizes and SHA-256 hashes. Models
are stored in the user's data folder. The online TTS implementation needs no
paid API key; this does not guarantee permanent access, unlimited quotas or
a license to another party's voices. Availability depends on the provider.

LOCAL VOICES
The optional Piper engine comes from official C++ release 2023.11.14-2, pinned
by size and SHA-256. Its code is MIT; components include ONNX Runtime (MIT),
piper-phonemize (MIT) and eSpeak NG (GPL-3.0-or-later), with their own notices.
Neither the engine nor voice models are bundled in Fábula's executable.
Corresponding sources and notices:

https://github.com/rhasspy/piper-phonemize

Current development: https://github.com/OHF-Voice/piper1-gpl

The SAPI bridge uses Windows System.Speech. Fábula does not distribute or install
proprietary voice packages or grant licenses to them. It enumerates compatible
installed voices and invokes their local speech synthesis.

Fábula's own code is GPL-3.0-or-later. That license does not replace model,
service or third-party component licenses. Original notices are preserved
in their original language and are not replaced by translated explanations.
