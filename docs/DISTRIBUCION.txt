DISTRIBUCIÓN DE FÁBULA

El repositorio contiene código, recursos, pruebas, lockfile y avisos. Los EXE,
modelos y datos de usuarios no se añaden al historial Git. GitHub Releases aloja
el instalador, portable, sus SHA-256 y las fuentes correspondientes.

PREPARAR LOS PAQUETES
1. Usa Windows x64 y Node.js 24 o posterior. Ejecuta npm ci, npm run build,
   npm test, npm run format:check y las comprobaciones de docs/CALIDAD.txt.
2. Revisa los avisos y las dependencias fijadas, y actualiza la versión.
3. npm run package:all genera Fabula.exe, Fabula-Instalador.exe y sus SHA-256
   en la raíz. Los archivos intermedios se guardan en .build.
4. Comprueba el portable, instalación ES/EN, idioma inicial y persistencia de
   preferencias y biblioteca al desinstalar. No uses datos personales.
5. Etiqueta el commit exacto. Adjunta EXE, SHA-256 y fuentes/notices a la misma
   Release. Verifica los archivos públicos antes de anunciar las descargas.

LICENCIAS Y FUENTES
Conserva LICENSE.txt, PRIVACIDAD.txt, AVISOS_DE_USO.txt, TERCEROS.txt,
LICENCIAS_DE_COMPONENTES.txt, assets/licenses/, los avisos de Electron/Chromium
y resources/media/. Las fuentes y archivos identificados en
assets/licenses/SOURCE_AVAILABILITY.txt deben seguir accesibles sin coste junto
a los paquetes. El ZIP automático del repositorio no contiene todas las fuentes
de los componentes nativos.
El runtime de audio se construye con tools/build-media.sh y el workflow
media-runtime.yml a partir de fuentes verificadas. assets/audio-runtime.json
fija los hashes del runtime y de sus fuentes. Las herramientas
preserve-canvas-licenses.mjs y preserve-ocr-licenses.mjs conservan las fuentes
y avisos exactos de las dependencias nativas.
Las fuentes MPL conservan MPL-2.0. La GPL de Fábula no cambia las licencias de
terceros. No añadas restricciones a modificación o ingeniería inversa permitida
por sus licencias. Los modelos de voz y módulos opcionales se descargan aparte;
no redistribuyas modelos sin revisar su licencia y conservar MODEL_CARD.

FUNCIONAMIENTO
Windows SAPI y Piper procesan localmente. No se distribuyen paquetes de voces
Windows. Ambos formatos usan %APPDATA%/Fábula y deben ejecutarse de uno en uno.
El portable funciona sin instalación y conserva sus datos fuera del EXE. El
instalador permite elegir carpeta, accesos directos e idioma. Desinstalar
conserva la biblioteca. Los paquetes no están firmados digitalmente.
En instalación silenciosa se admite /APP_LANGUAGE=es o /APP_LANGUAGE=en;
una preferencia de usuario existente siempre tiene prioridad.
